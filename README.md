# 棋类对战平台（OOP 大作业第一阶段）

基于控制台的棋类对战平台，目前支持五子棋与围棋的双人对战。

## 运行方式

```
python main.py
```

## 功能

- 五子棋 / 围棋双人交替落子，可自选棋盘大小（8x8 至 19x19）
- 围棋支持提子、禁自杀、打劫（禁全局同形）、虚着与数子法终局判定
- 五子棋自动判断连五获胜与棋盘满平局
- 悔棋、投子认负、局面保存 / 读取
- 可隐藏 / 显示的操作提示，异常输入均有错误反馈

## 结构

- `board.py` 棋盘、坐标与棋子模型
- `game.py` 对局抽象与五子棋 / 围棋规则实现，含局面快照
- `controller.py` 游戏工厂与后端控制门面
- `console_ui.py` 控制台界面组件与建造者
- `main.py` 客户端命令循环与入口
